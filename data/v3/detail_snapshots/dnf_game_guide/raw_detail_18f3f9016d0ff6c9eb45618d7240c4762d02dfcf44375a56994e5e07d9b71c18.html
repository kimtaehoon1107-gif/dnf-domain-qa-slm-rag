제한 사항

레이드 시작 후 일정 시간 후부터 '폭룡왕의 겁화' 게이지가 차오릅니다.

폭룡왕의 겁화가 100%에 도달 시 공략이 실패합니다.

ㄴ 공략 실패 시 우편으로 입장권 '이어진 불꽃의 의지'가 지급됩니다.

전투에서 전멸하거나 후퇴할 경우 페널티를 받게 되어 일정 시간 동안 전투에 참여할 수 없습니다.

바칼을 조우한 이후 전투 이탈 시 해당 파티는 일정 시간 바칼을 다시 조우할 수 없습니다.

코인을 사용하여 부활할 경우 스킬 쿨타임이 회복되지 않습니다.

모든 던전은 파티 상태여야 진입이 가능합니다.

<기계 혁명 : 바칼 레이드> 던전에서 캐릭터의 일부 스킬이 약화됩니다.

해당 스킬 : 넨 가드, 궁극의 넨 가드, 축기, 칠링 팬스, 아이스 실드, 슬로우 힐, 큐어, 생명의 원천, 힐 윈드, 치유의 기도, 꼼꼼한 바느질

스킬 약화 정보는 바칼 공격대 채널에서 확인이 가능합니다.

빙결, 기절, 석화, 수면 내성이 -30% 감소합니다.

승리 조건

폭룡왕 바칼 토벌

사룡 스피라찌, 냉룡 스카사, 광룡 히스마를 모두 처치해야 바칼에게 마지막 일격을 가할 수 있습니다.

ㄴ 바칼의 HP는 잠겨 있으며, 사룡 스피라찌, 냉룡 스카사, 광룡 히스마를 처치할 때 마다 잠금이 해제됩니다.

폭룡왕의 정전 사룡의 혼백당 광룡의 멸진당 냉룡의 투한당

패배 조건

폭룡왕의 겁화가 100%에 도달 시 작전에 실패합니다.

폭룡왕의 겁화는 아래의 상황에서 상승합니다.

ㄴ 레이드 시작 후 일정 시간부터 폭룡왕의 겁화가 차오릅니다.

ㄴ 폭룡왕의 정전에 입장중인 파티가 없는 상태일 경우 더 빠르게 차오릅니다.

ㄴ 생성된 전진 몬스터가 작전 주둔지 도달 시 큰 폭으로 상승합니다.

ㄴ 사룡, 냉룡, 광룡이 깨어난 이후 해당 던전에 입장중인 상태가 아닐 시 일정 시간마다 '폭룡왕의 겁화'가 차오릅니다.

던전 입장 방식

· 플루크하펜을 통한 입장과 직접 입장이 가능합니다.

플루크하펜은 파티장만 조작이 가능합니다.

던전 진입로 플루크하펜

패스게이트에 파티장이 도달 시 모든 파티원을 데리고 던전으로 진입합니다.

플루크하펜으로 입장할 시, 하기 이미지처럼 이동 가능한 지역이 표기되며 파티장의 마우스 클릭으로 이동할 수 있습니다.

특정 지역의 경우, 해당 지역의 몬스터 처치 후 비활성 상태일 경우만 이동이 가능합니다.

ㄴ 공허한 혼창(아홉 꼬리 블로나)

ㄴ 폭룡왕의 정전 입구(마룡 바실리스크)

ㄴ 부동의 연못(한기의 게르다)

ㄴ 폐허 위의 화원(요룡 님파)

파티장이 던전 진입로에 도달 시, 파티가 해당 던전으로 진입합니다.

파티원이 해당 맵에 모여 있어야 이동이 가능합니다.

 

던전 구성

<기계 혁명 : 바칼 레이드>는 16개의 던전으로 구성되어 있습니다.

각 던전은 모두 연결되어 있으며, 던전을 넘어가더라도 적용중인 자버프 및 스킬 상태 등이 유지됩니다.

그 외 소모품, 쿨타임, 코인 사용 개수 등도 유지됩니다.

사룡 스피라찌, 냉룡 스카사, 광룡 히스마는 각자의 권역을 소유합니다.

용들은 깨어나면 자신의 권역에 지속적으로 상태이상 효과를 발동합니다. 

ㄴ 사룡 : 중독

- 사룡의 혼백당, 공허한 혼창, 빛바랜 금주고

ㄴ 냉룡 : 빙결

- 냉룡의 투한당, 부동의 연못, 먹구름 누각 

ㄴ 광룡 : 기절

현재 진행 중인 상태

몬스터의 상태는 등장 중/증원 중/이동 중/출현 중으로 나뉩니다.

ㄴ 등장 중 : 몬스터가 해당 위치에 나타납니다. 등장 시 색이 활성화됩니다.

ㄴ 증원 중 : 몬스터가 병력을 증원합니다. 병력은 해당 몬스터 앞쪽에서 생성됩니다.

ㄴ 이동 중 : 몬스터가 앞으로 한 칸 이동합니다.

ㄴ 출현 중 : 몬스터가 해당 위치에서 사라집니다. 

버프 획득 정보

· 몬스터 처치 시 획득할 수 있는 버프입니다.

몬스터 상세 정보

· 상황판에 몬스터 또는 버프 아이콘에 마우스 오버 시 세부 정보를 확인할 수 있습니다.

점유 던전 표기

· 현재 파티가 점유하고 있는 던전을 표기합니다.

· 현재 던전에서의 파티 위치를 표기합니다.

· 한 던전에 하나의 파티만 입장이 가능합니다.

용의 권역

· 처음 작전 시작 시 사룡 스피라찌, 냉룡 스카사, 광룡 히스마는 비 활동 상태입니다.

· 공격대가 최초 지휘관 급 몬스터를 조우하면 사룡 스피라찌, 냉룡 스카사, 광룡 히스마 중 1마리의 용이 랜덤하게 활성화됩니다.

· 용이 활성화 되면, 해당 용의 권역이 발현됩니다.

· 일정 시간동안 던전에 들어간 파티가 없을 경우 폭룡왕의 겁화 게이지가 일정량 차오릅니다.

폭룡왕의 정전

폭룡왕 바칼이 주둔하는 던전입니다.

· 폭룡왕 바칼 조우 시 일정 HP가 잠긴 상태로 조우하게 됩니다.

잠긴 HP는 3단계로 구분되며, 사룡 스피라찌, 냉룡 스카사, 광룡 히스마 처치 시 1마리 당 1단계씩 해금되며, 세 마리의 용을 처치하면 모두 해금됩니다.

폭룡왕의 단조(융합 무기 불의 숨결 옵션)

폭룡왕의 단조 사용 시 바칼 융합 무기에 불의 숨결 옵션을 부여할 수 있으며, 부여되는 불의 숨결 옵션은 지정된 옵션으로 부여됩니다.
- 폭룡왕의 단조 사용 시 부여되는 불의 숨결 옵션 : 공격 시 60초 동안 피해 증가 +7627 (최대 1중첩) / 버프력 +775
ㄴ 해당 옵션은 단조를 통한 최초의 불의 숨결 옵션 부여를 위한 옵션으로 옵션 변환에는 등장하지 않습니다.
- 불의 숨결 옵션은 기존 바칼 융합 무기 옵션에 1:1로 대응하여 존재하는 옵션이며, 스킬 공격력 증가 수치와 피해 증가 수치가 다르게 적용되어 있습니다.
- 하나의 바칼 융합 무기에 옵션 목록 상 같은 옵션 번호를 가진 원본 옵션과 불의 숨결 옵션이 동시에 존재할 수 없습니다.
- 불의 숨결 옵션은 기존 1옵션, 2옵션 위치에 존재할 수 없습니다.

왜곡된 차원의 큐브 - 불의 숨결 소모품을 사용하여 불의 숨결 옵션이 추가된 융합 무기의 불의 숨결 옵션을 변환할 수 있습니다.
