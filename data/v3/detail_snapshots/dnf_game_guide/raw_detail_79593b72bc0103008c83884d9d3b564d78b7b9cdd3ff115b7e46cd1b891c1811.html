콘텐츠 입장

'찾아오는 황혼' 퀘스트 클리어 시 레이드 <만들어진 신 나벨 레이드> 에 입장할 수 있습니다.

- <만들어진 신 나벨 레이드> 채널은 명성 47,684부터 입장이 가능합니다.

<만들어진 신 나벨 레이드> 채널에서 NPC [어린 아젤리아]를 통해 공격대를 생성할 수 있습니다.

- NPC [어린 아젤리아] 혹은 공격대 찾기 UI의 공격대 생성 버튼을 통해 생성이 가능합니다.

공격대 생성 혹은 가입 후 우측 지역으로 이동하여 NPC [어린 아젤리아]를 통해 콘텐츠를 시작할 수 있습니다.

콘텐츠 시작

레이드 시작

모든 인원이 '태초의 경계' 지역에 진입 후 공대장이 NPC [어린 아젤리아]의 레이드 시작 기능을 통해 투표를 진행할 수 있습니다.

모든 인원이 레이드 시작에 찬성하는 경우 레이드가 시작됩니다.

공격대 포기

공대장이 레이드 진행 도중 NPC의 공격대 포기 기능을 통해 투표를 진행할 수 있습니다.

투표 진행 시간 내에 모든 인원이 공격대 포기에 찬성하는 경우 레이드 진행이 종료됩니다.

- 레이드 진행 종료 후, 레이드 주간 입장 제한 횟수가 복구됩니다.

- 투표 진행 시간 내에 아무 입력이 없는 인원은 찬성 처리됩니다.

- 이후 일반 / 하드 난이도의 경우 공격대 재생성 투표를 진행하여 공격대를 기존 인원으로 재편성 할 수 있습니다.

공격대 재생성

일반 / 하드 난이도의 경우 레이드 공략에 실패하거나, 공격대 포기 기능으로 레이드가 종료된 경우, 공격대 재생성 투표가 진행됩니다.

투표 종료 시, 공격대 재생성에 찬성한 인원으로 공격대가 재편성됩니다.

- 투표에 반대한 인원은 공격대 구성에서 제외되어 공격대에서 탈퇴됩니다.

- 투표 진행 시간 내에 중 아무 입력이 없는 인원은 반대 처리됩니다.

콘텐츠 규칙

콘텐츠 실패

자각의 경계(제한 시간) 소진 시 실패 처리됩니다.

실패/포기 시 주간 입장 횟수가 복구됩니다.

제한 사항

레이드 시작 시 '자각의 경계' (제한 시간) 가 적용됩니다.

- 자각의 경계는 시간의 흐름에 따라 자연 감소 하게 됩니다.

- 일반 / 하드 난이도의 경우 아래 사항에 의하여 자각의 경계가 추가 감소 할 수 있습니다.

ㄴ'안개신의 무의식', '만들어진 신 나벨', '무지의 악 나벨'의 캐스팅 공격

일반 / 하드 난이도의 경우 코인 사용 횟수가 제한됩니다.

- 코인 사용 횟수는 파티 단위로 공유됩니다.

- 레이드 시작 시 총 5개의 코인 사용 횟수가 충전되며, 부활 시 코인 1개가 소진됩니다.

- 공격대 버프 또는, 특수 몬스터 처치 시 코인이 갱신됩니다.

싱글 / 매칭 난이도의 경우 코인을 사용하지 않고, 사망 시 자동 부활 처리가 됩니다.

회복형 소모품 사용 횟수가 각 몬스터 전투 별 제한됩니다.

- 각 몬스터와 전투 시작 시, 회복형 소모품 및 던전앤라이프 투척 소모품 사용 횟수가 8개로 제한됩니다.

- 인형류 소모품 사용이 제한됩니다.

지역 버프

지역 버프 '안개신의 염원' 버프가 적용됩니다.

- 전용 채널 마을에서 '안개신의 염원' 버프가 적용됩니다.

- 던전 입장 시 힘, 지능이 상승합니다.

ㄴ '안개신의 염원' 버프로 인한 능력치 상승은 버퍼의 버프 스킬에 영향을 주지 않습니다.

-매칭 난이도의 경우 파티 인원에 따른 데미지 증가 버프가 추가 적용됩니다.

회복 패널티

던전에서 전멸 혹은 후퇴로 인해 '악몽'으로 이동 시, 파티원 모두가 일정 시간동안 "회복 중" 상태가 적용됩니다.

- "회복 중" 상태인 파티원이 1명이라도 존재하는 경우, 전장으로 복귀할 수 없습니다.

- 후퇴한 횟수에 따라 "회복 중" 적용 시간이 증가합니다.

- '악몽'내 전투를 통해 회복 시간을 감소 시킬 수 있습니다.

전장 / 악몽

악몽

레이드 첫 시작 지점입니다.

특정 조건에 따라 다시 진입이 가능한 지역입니다.

- 구원의 손길 공격대 버프 사용

- 후퇴

- 대기실 복귀 후 재 진입

파티장이 상황판에서 원하는 전장을 우클릭하여 바로 순간이동 할 수 있는 지역입니다.

후퇴를 하여 진입 할 경우 회복 시간 패널티가 주어집니다.

- 회복 시간이 종료되면, 다시 전장으로 복귀할 수 있습니다.

'악몽'에서 대기실 버튼을 통해 '마을 대기실'로 되돌아 갈 수 있습니다.

회복 패널티가 적용된 파티의 경우 '무의식의 사념'과의 전투를 통하여 회복 패널티 시간을 단축할 수 있습니다.

전장

최대 3개의 파티가 격자 형태의 공간을 자유롭게 돌아 다니며 전투를 진행하는 꿈속의 전장입니다.

전장 : 7 X 7의 그리드로 구성된 '전장'은 '악몽'을 통해 진입이 가능합니다.

- 진입한 전장을 돌아다니며, '기억의 근원(포탈)'을 통해 각 몬스터와 조우할 수 있습니다.

- '간섭' 가능 상태인 경우 다른 파티가 전투 중인 던전에 진입하여 전투를 진행할 수 있습니다.

ㄴ '간섭'을 통해 던전 진입 시 던전 진행 시간은 전투 중인 파티와 동일하게 진행됩니다.

- 일반/하드 난이도의 경우 아래 몬스터가 전장에 영향을 미치는 공격을 시행합니다.

- 전장 공격이 예정된 지역은 특수한 공격 위험에 노출되게 됩니다.

- 또한, 전장 공격이 실행된 지역은 일정시간 잔열 지대가 됩니다.

ㄴ 잔열 지대 : 영향 받는 모든 파티에게 파열 상태 이상 부여 / 해당 지역 몬스터에게 받는 피해 감소 적용

가드

'가드'는 <만들어진 신 나벨 레이드>의 모든 던전에서 '던전특수키1'에 지정된 키를 통하여 사용할 수 있습니다.

- ESC → 설정 → 단축키에서 설정 가능합니다.

'가드'는 특수한 자세를 취해 몬스터의 공격을 막아내거나 특수한 공격을 파훼합니다.

- 각성 스킬과 특정 상태를 제외한 행동을 캔슬하여 사용이 가능합니다.

- 시전 중 점프키를 통하여 가드 자세를 캔슬할 수 있습니다.

- 모든 던전 입장 시 '가드게이지'는 초기화 되어 1칸이 회복되어 있는 상태가 됩니다.

- '가드게이지'는 최대 3칸 까지 제공되며, 시간 경과에 따라 '가드게이지'를 회복 할 수 있습니다.

파훼가 가능한 몬스터의 특수한 공격은 다음과 같습니다.

- 보라색/흰색 워닝

ㄴ 보라색/흰색 워닝을 '가드'에 성공 시 소모된 '가드게이지'가 즉시 회복됩니다.

ㄴ 몬스터에 따라 추가적으로 패턴을 파훼하거나 전투에 유리한 상황을 제공하게 됩니다.

- 방패 마크

ㄴ 보라색/흰색 워닝 중 일부는 방패 마크가 제공됩니다.

ㄴ 방패 마크가 있는 공격에 '가드'에 성공 시 소모된 '가드게이지'가 즉시 회복됩니다.

ㄴ 위의 일반적인 보라색/흰색 워닝에 비해 더 큰 이점을 제공합니다.

싱글

1인으로 진행 가능한 난이도로 '무의지의 장벽'의 파괴가 목표입니다.

진행 방식

'무의지의 장벽'은 '연구소장 엘디르'에 의해 보호 되고 있습니다.(처치 시 조우 가능 상태가됩니다.)

'연구소장 엘디르'는 아래의 몬스터로 인해 강화 된 상태이며, 해당 몬스터 처치 시 강화 상태가 해제됩니다. (총 3단계)

- 과학자 모리

- 손의 트라우마트

- 아래 3종 몬스터 중 1개체

ㄴ 파괴의 트라우마트

ㄴ 전쟁의 트라우마트

ㄴ 참혹의 트라우마트

매칭

매칭을 통하여 최대 12인(최소 6인)으로 진행 가능한 난이도로 '무의지의 장벽'의 파괴가 목표입니다.

파티 매칭

최대 4인 까지 파티를 구성하여 매칭을 시도할 수 있습니다.

구성된 파티는 매칭을 통하여 생성된 공격대에서 같은 파티에 속하게 됩니다.

매칭 모드에서 버퍼 직업군의 마법부여, 시너지 장비의 경우 싱글 플레이 옵션이 발동됩니다.

고의적으로 진행을 방해하는 일부 유저의 경우 일정기간 매칭 난이도 이용 불가 처리가 됩니다.

진행 방식

각 파티는 파티 별 담당 구역에서 전투를 진행하게 됩니다.

'무의지의 장벽'은 각 구역의 마지막 몬스터에 의해 보호되고 있습니다.

- 각 파티의 담당 구역의 마지막 몬스터 처치 시 '무의지의 장벽'의 HP 잠금을 해제 할 수 있습니다.

각 파티 별 담당 구역의 마지막 몬스터 처치 시 다음 행동을 할 수 있습니다.

- 무의지의 장벽 조우

- 다른 파티의 구역 진입

- 다른 파티가 전투 중인 몬스터 '간섭'

구역 마지막 몬스터는 다음과 같습니다.

- 연구소장 엘디르

- 최후의 테아나

- 죽음의 트라우마트

모든 몬스터의 경우 몬스터 조우 시점의 파티 인원수에 따른 데미지 증가 버프가 적용됩니다.

일반

구성된 12인의 인원으로 진행 가능한 난이도로 '무지의 악 나벨'의 처치가 목표입니다.

공격대 버프

'나벨'의 공략에 도움을 주는 액티브 버프 5종이 제공됩니다.

- 버프는 각 파티장이 사용할 수 있습니다.

- 각 버프의 사용 횟수는 모든 파티가 공유합니다.

- 각 버프는 쿨타임을 통해 사용 횟수가 충전됩니다.

잠식

다음 몬스터를 조우한 파티원의 경우 던전 종료 후 일정 시간 잠식 상태에 놓이게 됩니다.

- 나벨 : '무의지의 장벽', '만들어진 신 나벨', '무지의 악 나벨'

- 아니마 : '인공신 아니마', '오만의 악 아니마'

- 엘디르 : '연구소장 엘디르', '선각자 엘디르'

각각의 몬스터는 개별적인 잠식 상태를 가지게 됩니다. 해당 상태는 상황판을 통하여 확인 가능합니다.

- 예시1 : '나벨' 조우 후 일정 시간 '나벨' 재조우 불가

- 예시2 : '나벨' 조우 후 '아니마' 또는, '엘디르' 조우 가능

잠식 상태인 파티원이 1명이라도 존재하는 경우, 해당 몬스터를 조우할 수 없습니다.

진행

'무의지의 장벽' 파괴 시 '만들어진 신 나벨'이 깨어나게 됩니다.

보스 설명 제한
무의지의 장벽
  • '무의지의 장벽'이 특수한 상태에 놓이게 됩니다.
    • 꿈의 붕괴 : '무의지의 장벽'과 조우 할 수 있는 시간을 제한합니다.
  • 던전 제한 시간 초과에 따른 회복 패널티가 해제됩니다.
  • 조우한 파티에 '나벨' 잠식이 부여됩니다.
만들어진 신 나벨
  • 전투 후 감소된 HP가 유지됩니다.
  • 캐스팅 완료 시 '자각의 경계'를 대량 감소시킵니다.
무지의 악 나벨
  • 전투 후 감소된 HP가 유지됩니다.
  • 캐스팅 완료 시 '자각의 경계'를 대량 감소시킵니다.
  • 전투 후 다른 지역으로 이동 및 재생성 상태에 돌입합니다.

 

다음 몬스터들에게 각각의 특수한 역할이 부여됩니다.

보스 설명 제한
연구소장 엘디르
  • 전투 후 감소된 HP가 유지됩니다.
  • '무의지의 장벽'을 강화(받는 피해 감소 99%)하는 중입니다.
  • 던전 제한 시간 초과에 따른 회복 패널티가 해제됩니다.
  • 조우한 파티에 '엘디르' 잠식이 부여됩니다.
선각자 엘디르
  • 전투 후 감소된 HP가 유지됩니다.
  • '무지의 악 나벨'에게 '새겨진 신의 힘(HP 잠금)'을 적용 중입니다.
인공신 아니마
  • 전투 후 감소된 HP가 유지됩니다.
  • '만들어진 신 나벨'에게 '새겨진 신의 힘(HP 잠금)'을 적용 중입니다.
  • 던전 제한 시간 초과에 따른 회복 패널티가 해제됩니다.
  • 조우한 파티에 '아니마' 잠식이 부여됩니다.
오만의 악 아니마
  • 전투 후 감소된 HP가 유지됩니다.
  • '무지의 악 나벨'에게 '새겨진 신의 힘(HP 잠금)'을 적용 중입니다.
과학자 모리
  • 캐스팅 완료 시 모든 몬스터 받는 피해 감소('과학자 모리' 제외)가 실행됩니다.
  • 처치 시 일정 시간 뒤 재생성됩니다.
최후의 테아나
  • 처치 시 일정 시간 모든 공대원의 최종 데미지가 증가됩니다.
  • 처치 시, '나벨'의 페이즈가 전환 될 때 재생성됩니다.
손의 트라우마트
  • 캐스팅 완료 시 전장내 생성, 전투 중이 아닌 전장 공격 몬스터 1개체를 강화합니다. 
    • 단, 강화 대상이 없을 경우 전장 공격 몬스터 1개체를 소환합니다.
  • 처치 시 일정 시간 뒤 재생성됩니다.
죽음의 트라우마트
  • 처치 시 '두려움의 근원'('나벨' 그로기 발생 오브젝트)을 생성합니다.
  • '나벨' 페이즈 전환 시 '죽음의 트라우마트'가 강화됩니다.
  • 처치 시, '나벨'의 페이즈가 전환 될 때 재생성됩니다.
안개신의 무의식
  • 일정 시간 마다 전장에 생성됩니다.
  • 캐스팅 완료 시 '자각의 경계'를 소량 감소시킵니다.
  • 4회 캐스팅 완료 후 다른 지역으로 이동 후 재생성됩니다.
무의식의 잔재
  • '만들어진 신 나벨'이 깨어날 시 전장에 생성되며, 처치 시 다른 지역으로 이동 후 재생성됩니다.
  • 처치 시 처치한 파티의 소모된 코인이 소량 회복됩니다.

하드

구성된 12인의 인원으로 진행 가능한 도전적 난이도로 '무지의 악 나벨'의 처치가 목표입니다.

일반 난이도 대비 하드 난이도의 주요 변경 사항은 아래와 같습니다.

진행

'만들어진 신 나벨'이 깨어난 상태로 시작되며, 전장 내 모든 몬스터가 받는 피해가 감소됩니다.

몬스터 패턴 파훼에 따른 보너스 수치가 일반 난이도 대비 증가합니다.

'무지의 악 나벨'에게만 '새겨진 신의 힘(HP 잠금)'이 적용됩니다.

'연구소장 엘디르' 처치 시 '선각자 엘디르'로 전투가 이어집니다.

'죽음의 트라우마트'가 강화된 상태로 출현하게 됩니다.

'엘디르'와 '아니마'에게 각각의 특수한 역할이 부여됩니다.

- 전투 제한 시간 초과 시 '엘디르'와 '아니마'의 캐스팅이 취소됩니다.

  • 캐스팅 완료 시 '나벨'과 조우 중인 모든 파티에게 파열 상태를 부여합니다.

'가드게이지' 최대 칸수가 2칸으로 변경됩니다.
