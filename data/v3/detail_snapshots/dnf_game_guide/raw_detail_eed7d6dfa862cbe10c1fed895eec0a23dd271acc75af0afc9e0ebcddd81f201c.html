공격대 생성 혹은 가입 후 우측 지역으로 이동하여 NPC '3대대 부관 철편자 카르케오'를 통해 콘텐츠를 시작할 수 있습니다.

 

콘텐츠 규칙

콘텐츠 실패

요기 게이지가 100%가 되면 실패 처리됩니다.

실패 시 주간 입장 횟수가 복구됩니다.

제한 사항

코인 사용 횟수가 제한됩니다.

- 코인 사용 횟수는 공격대 단위로 공유됩니다.

- 레이드 시작 시 총 10개의 코인이 충전되며 부활 시 코인 1개가 소진됩니다.

- 싱글 / 매칭 난이도의 경우 코인을 사용하지 않고, 사망 시 자동 부활 처리됩니다.

회복형 소모품 사용 횟수가 제한됩니다.

- 소모품 사용 횟수는 개별 단위로 적용됩니다.

- 레이드 시작 시 7번의 소모품 사용 횟수가 충전됩니다.

- 인형류 소모품 사용이 제한됩니다.

콘텐츠 진행 중 특정 던전 클리어 시 코인 1개와 모든 공대원의 소모품 사용 횟수 2회를 획득할 수 있습니다.

- 1페이즈 - 요기 폭탄 운반자 처치 시

- 2페이즈 - 역병의 씨앗 처치 시

지역 버프

지역 버프 '결착의 시간' 버프가 추가됩니다.

디레지에 레이드 전용 채널에서 결착의 시간 버프가 적용됩니다.

던전 입장 시 힘, 지능이 상승합니다.

레이드 시작

배율 설정

디레지에 레이드 파티 생성 시 몬스터의 HP 배율을 설정할 수 있습니다.

최소 0% 부터 최대 500% 까지 50%단위로 설정하실 수 있습니다.

설정 시 몬스터의 HP 가 해당 % 만큼 상승합니다.

전투준비

모든 인원이 '애쥬어 메인' 지역에 진입 후 공대장이 NPC [3대대 부관 철편자 카르케오]의 레이드 시작 기능을 통해 전투준비 완료 여부에 대한 투표를 진행할 수 있습니다.

모든 인원이 전투준비를 완료하면, 레이드가 시작됩니다.

디레지에 레이드 전투준비 UI에서는 다른 공대원의 아바타와 파티편성 색상을 확인할 수 있습니다.

공통 시스템

섬

중천의 혈광촌, 군도, 별의 쉼터, 이내 섬이 배치되어 있습니다.

섬 파괴 시 요기 게이지가 상승합니다.

세인트혼 호출

파티장은 레이드 특수키( ` ) 버튼을 사용하여 원하는 위치로 이동할 수 있습니다.

- 6초의 쿨타임을 가지고 있습니다.

사용 시 파티원이 모두 함께 이동합니다.

자각의 권능 - 역병 반전

역병 반전 게이지가 모두 차게되면 던전 특수키(Tab)로 사용할 수 있습니다.

역병 반전 게이지는 특정 던전을 클리어하면 추가 회복할 수 있습니다.

- 요기 폭탄 운반자 처치 시

- 역병지대 처치 시

- 디레지에 및 뒤얽힌 사념 처치 시

역병 반전 사용 시 던전 특수키를 길게 눌러 3초간 유지할 수 있습니다.

원할 때 던전 특수키를 때서 발동시킬 수 있습니다.

몬스터의 눈이 붉게 빛날 때 사용 시 효과가 더욱 강력해집니다.

콘텐츠 시작 시 임의의 공대원 3명이 역병 반전 게이지가 모두 회복된 상태로 시작됩니다.

몬스터 AI

특정 몬스터는 상황에 따라 지역을 이동합니다.

매복

특정 몬스터가 이동할 때 미리 이동할 위치에 플레이어가 있으면 매복 효과가 발생합니다.

매복 효과로 전투 진입 시 그로기 타임을 제공하며 각성기를 제외한 쿨타임이 초기화됩니다.

1페이즈 - 진격

구성

구역에 맞는 요괴 부대와 네임드 3종, 환요오괴 4종이 배치됩니다.

불신의 초원 그믐달 호수 버려진 사막 울분의 대지
네임드 실험체 에레드 속삭이는 라디나 관리자 베르데 -
환요오괴 만개한 불신 라르고 붕괴한 광신 마흐나발 왜곡된 욕신 루브라 비정의 셀게이퍼

최종 보스인 비정의 셀게이퍼 처치 시 1페이즈가 클리어됩니다.

안개의 자락

네임드 및 환요오괴를 처치하면 안개의 자락 게이지를 회복시킬 수 있습니다.

안개의 자락 게이지가 모두 차게되면 안개신의 강력한 버프를 획득할 수 있습니다.

- 1페이즈 - 진격에서 가하는 최종 데미지 30% 증가

요괴 부대

필드에 생성되는 요괴 부대를 처치 시 해당 지역에 관련된 환요오괴를 불러올 수 있습니다.

요기 폭탄 운반자

섬 앞에 소환되는 요기 폭탄 운반자는 일정 시간동안 처치하지 않으면 섬의 HP를 감소시키고 요기 게이지를 상승시킵니다.

요기 폭탄 운반자를 처치하면 모든 공대원의 역병 반전 게이지가 회복됩니다.

요기 폭탄 운반자를 처치하면 코인 1개와 모든 공대원의 소모품 사용 횟수 2회를 획득할 수 있습니다.

네임드 몬스터

일정 시간동안 처치하지 않으면 요기 게이지를 상승시킵니다.

네임드 중 랜덤한 1마리의 몬스터는 강화된 상태로 생성됩니다.

- HP가 증가됩니다.

- 일정 시간동안 처치하지 않으면 요기 게이지를 대폭 상승시킵니다.

네임드 처치 시 같은 지역 환요오괴의 받는 데미지가 증가합니다.

불신의 초원 그믐달 호수 버려진 사막
네임드 실험체 에레드 속삭이는 라디나 관리자 베르데
환요오괴 만개한 불신 라르고 붕괴한 광신 마흐나발 왜곡된 욕신 루브라
효과 받는 데미지 50% 증가

환요오괴

셀게이퍼를 제외한 환요오괴들은 일정 시간 뒤 빈 섬으로 이동합니다.

환요오괴가 섬에 머무르게되면 섬의 HP가 서서히 감소합니다.

환요오괴가 파괴된 섬 위치에 있다면 지속적으로 요기 게이지를 상승시킵니다.

환요오괴 처치 시 비정의 셀게이퍼의 받는 데미지가 30% 증가합니다. (최대 90%)

비정의 셀게이퍼

주기적으로 필드에 요괴 부대 및 요기 폭탄 운반자를 생성합니다.

안개의 자락 버프가 발동되면 새로운 요괴 부대를 소환합니다.

- 포식으로 지정된 몬스터가 죽으면 체력을 회복할 수 없습니다.

- 공포 상태에서는 '더러운 피를 흘리는 자'와 전투가 불가능합니다.

4페이즈 - 악연의 끝

구성

안개신이 등장해 모든 플레이어를 더러운 피를 흘리는 자의 요람으로 이동시킵니다.
