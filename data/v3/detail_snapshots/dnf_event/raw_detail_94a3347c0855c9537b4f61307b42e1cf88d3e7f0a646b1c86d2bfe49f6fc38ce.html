[썸머 부스트업 캡슐]

- 썸머 부스트 업 캡슐은 최고 명성 63,257 미만의 전체 대상 캐릭터 1종 / 인파이터(여) 캐릭터 1종 / 브레이커 캐릭터 1종, 총 3번 지정 가능합니다.

- 최고 명성은 캐릭터가 지금까지 달성한 가장 높은 명성 수치를 의미합니다.

- 썸머 부스트 업 캡슐은 계정귀속 상태로 지급되며, 8/27(목) 점검 전까지 사용 가능합니다.

- 썸머 부스트 업 캡슐은 세리아방에서만 사용 가능합니다.

- 썸머 부스트 업 캡슐 사용 가능 캐릭터로 접속 시 이벤트 창에서 적합한 캡슐의 받기 버튼에 강조 연출이 표시됩니다.  해당 받기 버튼을 클릭할 경우, 캡슐을 즉시 사용할 수 있는 팝업이 노출됩니다.

- 던전앤파이터에 익숙하지 않은 모험가 님을 대상으로 전용 캡슐 지급 이벤트창이 출력됩니다. 일반 이벤트창과 기능은 동일하며, 지급되는 캡슐도 동일합니다.  (이벤트창 종류에 관계 없이 이미 수령한 캡슐은 재수령할 수 없습니다.)

[이벤트 캐릭터 지정]

- 썸머 부스트 업 캡슐 사용 후에 이벤트 캐릭터로 지정된 캐릭터는 이벤트 기간 중 다른 캐릭터로 변경할 수 없습니다.

- 이벤트 캐릭터는 이벤트 종료 전까지 삭제가 불가능합니다.

- 오디세이 모드로 생성한 캐릭터를 지정 시, 사용된 오디세이 모드 생성 횟수가 즉시 복구됩니다.  단, 복구는 캐릭터를 생성한 월에만 가능합니다.  참고) 오디세이 모드 캐릭터 생성 가능 횟수: 매월 1일 06시 초기화

- 오디세이 모드 보상은 달성한 레벨 구간까지 지급됩니다.

[트레이닝 시뮬레이션 모드]

- 트레이닝 시뮬레이션 모드는 총 8단계로 구성되어 있으며, 각 단계는 성장에 도움이 되는 가이드 미션 및 보상들로 구성되어 있습니다.

- 이전 단계를 클리어 해야 다음 단계가 순차적으로 오픈됩니다.

- 부스트 업 캡슐 사용 시 장비 인벤토리에 여유 슬롯이 23칸 이상 확보되어 있지 않은 경우, 트레이닝 준비 없이 1단계 보상이 인벤토리로 바로 지급됩니다.

- 트레이닝 시뮬레이션 모드에서는 피로도가 소모되지 않으며, 115레벨 이상으로 성장하지 않습니다.

- 트레이닝 시뮬레이션 모드에 진입 시에 즉시 115Lv로 레벨업하며 완료되지 않은 장비 슬롯 오픈/1차, 2차, 진 각성 퀘스트는 자동으로 완료됩니다.

- 이미 115Lv 달성한 캐릭터는 추가로 레벨이 오르지 않습니다.

- 트레이닝 시뮬레이션 모드의 모든 미션을 완료하기 전까지는 다른 장소로 이동할 수 없습니다.

- 트레이닝 시뮬레이션 모드를 진행 중인 캐릭터는 8/27(목) 점검 후에 참여할 수 없습니다.

- 미션 보상은 미션 달성 시 인벤토리로 바로 지급되며, 공간이 부족할 경우 우편(보관 기간: 8/27(목) 점검 전까지)으로 지급됩니다.

- 부스트 업 캡슐을 사용하여 115Lv을 달성하는 경우, 트레이닝 시뮬레이션 모드 종료 후 115레벨 달성 상자(부스트 업 전용)가 지급됩니다.

- 115레벨 달성 상자(부스트 업 전용)는 트레이닝 시뮬레이션 완료 시 우편함으로 지급됩니다. (우편함 보관 기간은 15일)  단, 이벤트 기간 중에만 지급되며 종료 이후에는 지급되지 않습니다.

- 115레벨 달성 상자(부스트 업 전용) 사용 가능 기간은 트레이닝 시뮬레이션 완료 후 30일입니다.

- 115레벨 달성 상자(부스트 업 전용) 구성품: 115레벨 유니크 서약 결정 항아리 1개, 미광의 서약 결정 10개, 종말의 계시(기간 무제한) 700개, 체력 증강제 100개, 마력 증강제 100개

[부스트 업 챌린지 버프]

- 부스트 업 챌린지 버프는 이벤트 대상 캐릭터에만 적용되며, 이벤트 종료 시점까지 적용됩니다.

- 상급 던전 부스트 업 챌린지 버프는 달이 잠긴 호수, 애쥬어 메인, 죽음의 여신전에서만 적용됩니다.

- 레이드 부스트 업 챌린지 버프는 디레지에 : 서막 (싱글, 매칭)에서만 적용됩니다.

[부스트 업 챌린지 미션]

- 부스트 업 챌린지 미션 보상은 보상 획득 조건 달성 후, [받기] 버튼 클릭 시 우편함으로 발송되며 우편 보관 기간은 15일입니다.

- 죽음의 여신전 클리어 미션은 해방된 흉몽(일반) 같은 상위 상급 던전을 클리어해도 함께 카운트됩니다.

- 검은 질병의 디레지에 클리어 미션은 난이도와 무관합니다. (싱글/매칭/일반/하드 중 1개 난이도만 클리어해도 카운트됩니다.)

- 해방된 흉몽(일반) 클리어 미션은 해방된 흉몽 일반 난이도를 클리어 하거나, 별거북 대서고, 배교자의 성, 최후의 과업 같은 상위 상급 던전을 클리어해도 함께 카운트됩니다.

[부스트 업 가이드 미션]

- 부스트 업 가이드 미션 보상은 보상 획득 조건 달성 후, [받기] 버튼 클릭 시 우편함으로 발송되며 우편 보관 기간은 15일입니다.

- 서약 포인트 N 달성하기 미션에서 서약 포인트는 세트 포인트 보정 수치를 포함한 전체 서약 포인트를 기준으로 산정 합니다.

- 수리하기 미션에서는 골드를 사용한 수리, 쿠폰을 사용한 수리 케이스를 모두 카운트 합니다.
