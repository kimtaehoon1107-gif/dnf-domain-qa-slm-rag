FAQ 1:1문의 선복구 원격지원 보안 던파ON 관리

FAQ

삭제
전체 아이디정보/보안 설치/실행 게임문의 복구 결제 PC방 이벤트 던파ON
  • [이벤트] 태초 레거시 무기/악세서리 선택 상자는 잘못 선택해도 변경할 수 있나요?

    상자 최초 개봉 시 계정귀속 상자로 바꿀 수 있는 변환서를 1회 획득할 수 있습니다.

    변환서 사용 이후 상자 개봉 시 과실복구가 가능하지 않으니 필요한 캐릭터에 사용하는 것이 맞는지 꼭! 확인해 주세요. 

  • [이벤트] 회로 제작 도중 안정도가 0%가 되면 어떻게 되나요?

    안정도가 0%에 도달하면 회로 제작이 즉시 종료되며, 그 시점까지 활성화된 모듈 수에 해당하는 보상을 획득합니다. 

  • [이벤트] 기초 데이터는 어디에서 획득할 수 있나요?

    천해천 적정 레벨 던전(조율의 경계·최후의 조율자·천해를 품은 하늘)과

    중천/천해천 상급 던전(달이 잠긴 호수·애쥬어 메인·죽음의 여신전·해방된 흉몽(챌린지 제외)·별거북 대서고·배교자의 성·최후의 과업)

    보스 처치 시 획득합니다.

  • [이벤트] 기초 데이터와 천칭 진행도는 언제 초기화되나요?
    매주 목요일 06시에 기초 데이터, 천칭 시뮬레이션 진행도, 탐색 드론 버프 레벨이 모두 일괄 초기화됩니다.
  • [게임 이용] '광휘의 행로'는 어떻게 이용하나요? 무료 탐사는 언제 초기화되나요?

    '광휘의 행로'는 NPC를 통해 탐사를 보내고 일정 시간 후 보상을 받는 콘텐츠입니다. 

    주간 1회 무료 탐사가 가능하며, 매주 목요일 오전 6시에 초기화됩니다.

  • [이벤트] 출시 기념 쿠폰은 언제까지 입력할 수 있나요?

    쿠폰 코드 「새로운칼날을맞이하라」는 2026년 6월 4일(목) 점검 후부터 8월 27일(목) 점검 전까지 입력 가능합니다. 

  • [이벤트] 인파이터(여)&브레이커의 Special Gift 궁금한 점이 있어요.
    Q. 보상은 몇 번까지 획득할 수 있나요?
    A. 보상은 계정당 1회 획득할 수 있습니다.

    Q. 지급되는 크리쳐에 별도 옵션이 있나요?
    A 크리쳐는 교환불가,무제한 상태로 지급되며 별도 옵션이 존재하지 않습니다.​

  • [네이버 로그인 계정 이벤트] [혜택 1,2] Napy 포인트 예상 적립금은 어떻게 확인할 수 있나요?

    결제 진행 시, Npay 결제창 하단에서 구매 적립과 이벤트 적립으로 구분하여 확인하실 수 있습니다.

    결제 이후에는 [Npay > 포인트내역] 에서 확인하실 수 있습니다.

     

    - 이벤트 적립

     * 머니 프로모션 적립 → 5/18(월)~7/20(월) 기간 동안 [혜택2]로 제공되는 추가 0.5% 적립금

    ​ * ​첫 결제 프로모션 적립 → 5/18(월)~6/24(수) 기간 동안 [혜택1]로 제공되는 10% 페이백 적립금 (최대 5,000P)

     

    - 구매적립

    ​ * ​머니 결제적립 → [혜택2]로 제공되는 기본 0.5% 적립금 (상시 적립)​

     

    Npay 포인트 적립 관련 문의사항은 Npay 고객센터(1:1 문의 바로가기>)로 접수해주시기 바랍니다.

  • [네이버 로그인 계정 이벤트] [혜택 1] Npay 포인트로 결제해도 추가 적립이 되나요?

    아니요, 추가 적립은 Npay 머니 충전결제 건에 한해 적용됩니다.​

     

    다만, Npay 포인트를 일부 사용하고 차액을 Npay 머니 충전결제로 결제하는 경우,

    해당 Npay 머니 충전결제 금액에 대해서는 추가 적립이 적용됩니다.​ 

  • [네이버 로그인 계정 이벤트] [혜택 3] 아이템 미사용 상태인데, 다른 게임 아이템으로 변경할 수 있나요?

    넥슨ID당 1회, 한 가지 게임을 선택해 아이템 수령이 가능하며,

    보상 수령이 완료된 이후에는 다른 게임 아이템으로 변경하실 수 없습니다.​ 

  • [네이버 로그인 계정 이벤트] 필수 약관만 동의했는데, 추후 선택 약관도 동의하면 혜택을 받을 수 있나요?

    이벤트 기간 내에 선택 약관까지 모두 동의를 완료하시면,

    [혜택3]과 [혜택4] 보상을 받으실 수 있습니다.​

     

    선택 약관은 게임 아이템 선택 화면에서

    [동의하고 보상받기] 버튼을 클릭하여 추가로 동의하실 수 있습니다.​

     

    [넥슨 X 네이버 이벤트 페이지]​​ 

  • [네이버 로그인 계정 이벤트] [혜택 1,2] 계정 변경 후 Npay 결제를 진행했는데 포인트가 들어오지 않아요.

    혜택1, 혜택2를 통해 제공되는 Npay 포인트는 결제완료 시점으로부터 7일 이후에 적립되며,

    Npay 결제 시에 로그인한 네이버페이ID를 기준으로 적립됩니다.

     

    추가로 혜택2의 경우 Npay 머니 충전 결제를 이용해야 보상이 제공됩니다.​ 

  • [네이버 로그인 계정 이벤트] [혜택 1,2] 잘못 결제하여 결제를 취소했습니다. 다시 참여할 수 있나요?

    혜택1, 혜택2 보상이 지급되는 결제 건을 취소한 경우,

    Npay 포인트 정책에 따라 적립 포인트가 취소 또는 회수될 수 있습니다.

     

    ​혜택1의 경우 결제 취소 이후,

    이벤트 기간 내에 조건을 만족하는 결제를 추가 진행하면,

    해당 결제 건에 대한 Npay 포인트 보상이 다시 지급됩니다.​ 

  • [네이버 로그인 계정 이벤트] [혜택 3] 네이버 로그인 계정으로 변경했는데 게임 아이템을 받을 수 없어요.

    네이버 로그인 계정으로 변경하였더라도,

    선택 약관에 모두 동의하지 않으면 [혜택3], [혜택4] 보상을 받으실 수 없습니다.​

     

    [동의하고 보상받기] 버튼을 클릭하여,

    선택 약관을 모두 동의하신 후 게임 아이템을 받아주세요!

     

    [넥슨 X 네이버 이벤트 페이지]​

  • [네이버 로그인 계정 변경] 네이버 로그인 계정이 무엇인가요?

    네이버ID를 사용해 넥슨에 로그인할 수 있는 계정으로,

    일반 네이버 간편 로그인 계정보다 조금 더 특별한 혜택을 받으실 수 있습니다.​

     

    네이버 로그인 계정은 [넥슨 X 네이버 이벤트] 페이지에서 변경 가능하며

    (1) 만 14세 이상, (2) 본인확인이 완료된 이메일ID, 간편 로그인 계정 이용 시에만 변경하실 수 있습니다.​ 

  • [네이버 로그인 계정 변경] 네이버 로그인 계정으로 변경하면, 어떤 혜택이 있나요?

    넥슨과 네이버가 준비한 다양한 혜택과 새로운 콘텐츠를 경험할 수 있습니다.

     

    이때, 필수 약관에 동의하시면 [혜택1]과 [혜택2]를 받으실 수 있고,

    선택 약관까지 모두 동의하시면 [혜택3]과 [혜택4]를 포함한 모든 혜택을 받으실 수 있습니다.

     

    [넥슨 X 네이버 이벤트 페이지]​​ 

  • [네이버 로그인 계정 변경] 네이버 로그인 계정으로 변경하면 기존 넥슨ID 정보가 사라지나요?

    아니요, 게임 플레이 기록과 넥슨캐시 및 넥슨ID 정보는 그대로 유지됩니다.

    로그인 방식만 네이버로 변경되는 것이니 안심하셔도 됩니다.​ 

  • [네이버 로그인 계정 변경] 네이버 간편 로그인 계정을 이용하고 있었는데, 이벤트 참여 방법이 있나요?

    기존에 네이버 간편 로그인 계정을 통해 넥슨을 이용하셨다면,

    간단한 절차를 통해 네이버 로그인 계정으로 변경 후 참여하실 수 있습니다.​

     

    계정 변경은 이벤트 페이지 내 [혜택 받으러 가기]를 클릭하여 진행하실 수 있습니다.

    [넥슨 X 네이버 이벤트 페이지]​

  • [네이버 로그인 계정 변경] 네이버 로그인 계정으로 변경 후, 넥슨ID 변경/본인인증 초기화 불가해요.

    네이버 로그인 계정으로 변경한 이후에는,

    변경일로부터 6개월 간 다른 넥슨ID로 변경할 수 없습니다.

     

    본인인증 초기화 또한 6개월이 경과한 시점부터 이용 가능합니다.​ 

  • [네이버 로그인 계정 변경] 넥슨ID 여러 개 모두 네이버 로그인 계정으로 변경할 수 있나요?

    네, 각각의 넥슨ID를 네이버 로그인 계정으로 변경할 수 있습니다.

    이 때, 넥슨ID 당 하나의 네이버ID를 사용하여 네이버 로그인 계정으로 변경할 수 있습니다.​
