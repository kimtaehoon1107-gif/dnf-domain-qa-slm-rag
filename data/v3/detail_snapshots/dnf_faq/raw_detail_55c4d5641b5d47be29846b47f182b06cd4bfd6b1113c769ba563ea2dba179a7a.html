    유선 네트워크(LAN) 환경에서 게임 이용을 권장 드립니다. ​

  • [설치/접속/실행 오류] 넥슨ID로 로그인하면 오류 팝업이 나타나요!!
    아래 발생되는 팝업 메시지 별 원인/해결 방법을 통해 조치해 보시고
    동일 증상이 계속될 시 1:1 문의 접수 부탁드립니다.

    [넥슨 로그인오류]
    1. 넥슨ID: 
    2. 로그인 시도 날짜: (최근 오류 메시지를 확인한 날짜)
    3. 이용하시는 백신 프로그램: 
    4. 오류메시지: 

    ─────────────────────────────────────── 

    [발생되는 메시지 별 원인/해결 방법]
    ① 요청시간을 초과했습니다.
    발생 원인: 네트워크 연결 상태 불안정 및 비정상적인 접속 시도 감지

    해결 방법:
    - 무선 네트워크(핫스팟/WIFI), 네트워크 우회(VPN)이 아닌 네트워크 환경에서 접속 시도
    - 동일 메시지 반복 시 충분한 시간 이후에 접속 시도 (일정 시간 이후 자동 해제)

    ② 등록되지 않은 ID이거나 ID 혹은 비밀번호를 잘못 입력하셨습니다.
    발생 원인: ID, 비밀번호 잘못 입력

    해결 방법:
    - 비밀번호 찾기를 통해 비밀번호 재설정 후 충분한 시간 이후에 로그인 시도

    ③ 비정상적인 접근 시도로 인해 일시적으로 차단이 되었습니다.
    발생 원인: 비정상적인 접근 시도 감지

    해결 방법:
    - 백신을 통한 악성코드/바이러스 정밀 검사
    - 동일 메시지 반복 시 충분한 시간 이후에 접속 시도 (일정 시간 이후 자동 해제)

    ④ 잘못된 요청으로 로그아웃됩니다.
    발생 원인: 이용 중 접속 장소/IP 변경 시 

    해결 방법:
    - 프록시, VPN, 공유기 상태에서 접속 중인지 확인
    - 프록시 or VPN → 연결 해제 후 이용 

     [프록시 해제 방법]
     - 엣지 실행 → 설정 → 시스템 및 성능 → 컴퓨터의 프록시 설정 열기 → 프록시 서버 사용 끔

     - 공유기 → LAN 선을 PC에 직접 연결

  • [튕김/끊김(렉)] 튕김 및 끊김 현상이 지속적으로 발생합니다.

    [넥슨ID/던파ID 원격 지원 서비스 바로가기]
    [네이버 채널링 ID 원격 지원 서비스 바로가기]

    ■ 주요 원인
    - PC / 그래픽 메모리 부족
    - 프로그램 충돌
    - 네트워크 불안정

    ■ 해결방법
    ① 불필요한 프로그램 정리
    - 작업관리자[Ctrl + Alt + Del] → 시작 앱 → 불필요한 프로그램 '사용 안함' 변경
    - 작업관리자[Ctrl + Alt + Del] → 프로세스 → 불필요 프로그램 종료 혹은 삭제

    ② 금융 보안 및 미사용 백신 프로그램제거
    - 금융 보안 프로그램 및 백신은 기능에 따라 PC를 실시간 감시하는 만큼
      프로그램 충돌 혹은 메모리 부족의 원인이 될 수 있습니다.

    ③ 모니터 주사율(새로고침 빈도)에 맞게 게임 설정 변경
    - 게임 실행 → 게임 설정 → 화면 
    - '수직 동기화' 체크 박스 해제 및 '초당 프레임 제한' 을 모니터 주사율에 맞게 조정 

    ※ 바탕화면 마우스 오른쪽 버튼 클릭 → 디스플레이 설정 → 고급 디스플레이 설정 → 새로 고침 빈도(모니터 주사율) 확인

    ④ 윈도우 최적화
    - 윈도우 10/11의 경우 자체적으로 실행되는 기능이 존재합니다.
      사용하지 않는 윈도우 기능을 비활성화하여 메모리 확보 및 프로그램 충돌을 줄일 수 있습니다.

    ※ 포털사이트에서 검색 시 확인되는 방법을 참고하여 진행 부탁드립니다.

    ⑤ 공유기 연결 문제 발생 시, 공유기 DMZ 설정
    - 시작 메뉴 → cmd.exe(명령 프롬프트) 실행 → ipconfig 입력
    - 기본 게이트웨이, IPv4 주소 확인 후 웹 브라우저 실행
    - 주소창에 기본 게이트웨이 입력 (예: 192.168.0.1)
    - 내부 IP 주소에 IPv4 주소 입력 후 저장

    ※공유기에 따라 설정 방법이 다를 수 있으니

  • [설치/접속/실행 오류] 해외에서도 던전앤파이터 이용이 가능한가요?
    던전앤파이터 한국서버는
    한국에 거주하고 계신 분들을 위해 서비스되고 있습니다.

    따라서, 해외에서는 던전앤파이터 홈페이지 혹은 게임 접속이
    원활하지 않거나 가능하지 않을 수 있는 점 양해 부탁드립니다.

    참고로 일본, 중국, 대만, 미국에서 던전앤파이터 해외 서비스가 진행 중인 만큼
    가급적 현지에서 제공되는 서비스를 이용 부탁드립니다.​

    - 바이러스/악성코드에 의한 충돌

    ■ 해결방법
    ① 백신 및 타 보안프로그램 종료 
    백신 프로그램 혹은 다른 보안프로그램(ex.뱅가드, Easy Anti-Cheat)에 의해
