```
현행   [189-212] '- 타이드 바운드 - 쿨타임이 감소합니다.'
```

인용 좌표 복원(32/32)과 `all_exposed_citations_exact`가 유지되는지 **반드시

### 통과 기준 (사전 등록)

```
     → 라이브에서 답변이 바뀌는지 확인. 바뀌면 전문 보고
```

## 4. ⚠️ 값 유형을 분리해 보고하십시오

`value_present`는 복합 서술형 골드에 위양성을 냅니다. M3에서 확인된 사례:

```
[A6-29] 사람 판정 = 정답 / value_present = none
  정답: ["무기 강화권[리노] 상자 2,000만 골드", …]
  pack: '| 상점판매가격 | 2,000만 골드 | 1,000만 골드 |'
  → 숫자는 둘 다 있는데 아이템명이 그 행에 없어 매칭 실패

[A6-17] 사람 판정 = 정답 / value_present = partial
```

**M3의 "숨겨진 누락 6건" 중 진짜는 4건입니다** (A6-1·7·13·26).
A6-17·29는 지표 한계입니다.

이번 라운드 보고에서 다음처럼 나누십시오.

```
numeric / date / time / currency   →  판정 게이트로 사용
descriptive (복합 서술형)           →  진단용. 게이트에서 제외
```

지표 자체의 재설계는 다음 라운드(R3)입니다. **이번에는 보고만 분리하면
됩니다.**
