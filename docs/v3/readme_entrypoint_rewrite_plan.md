## 0. 왜 하는가

저장소를 공개하면 방문자가 처음 보는 화면은 `README.md`다.
현재 상태로는 다음과 같이 읽힌다.

```
README.md (508줄, 영문)
  상단   "Latest v3 research track (2026-07-27)"    ← 낡음
  본문   v1/v2 빌드·학습·RAFT·LoRA 커맨드가 대부분
  언급   Product Free RAG: 0회
        PORTFOLIO.md:      0회
```

결과: **"SLM 파인튜닝 프로젝트구나"**로 오해하고 떠난다.
`PORTFOLIO.md`를 아무리 잘 써도 거기까지 도달하지 못한다.

이 라운드의 목표는 하나다. **방문자를 `PORTFOLIO.md`로 보낸다.**

## 1. 확정 사항

### 1-1. 언어

```
본문        한글
전문용어    원어 유지 — 무리해서 번역하지 않는다
```

원어로 두는 예:

> reranker, hybrid retrieval, chunk, embedding, verifier,
> sealed / adaptive, evidence, claim, one-shot, content-addressed,
> BM25, dense, RAG, fine-tuning, LoRA

번역하는 예:

> 검색, 근거, 인용, 봉인, 감수, 회귀 테스트, 코퍼스(그대로 써도 무방)

판단 기준: **한국어 개발자가 평소 그 단어를 어떻게 말하는가.**
"재순위 결정기"처럼 실무에서 아무도 안 쓰는 번역어를 만들지 말 것.

### 1-2. 읽는 사람

**넥슨 제출용이다.** 던파 도메인 전문가가 읽는다고 가정한다.

- 게임 용어(타이드 바운드, 질풍 개화 옵션, 세라샵 등) **설명하지 않는다**
- "던전앤파이터가 어떤 게임인지" 설명 **금지**
- 대신 **문서 구조를 얼마나 정확히 파악했는지**가 드러나게 쓴다

### 1-3. 범위 — 전면 재작성이 아니다

```
새로 쓴다      최상단 진입 블록
갈아엎는다     "Latest v3 research track" / "Latest Verified Status" 블록
격하한다       v1/v2 재현 커맨드 섹션들 → 하단으로, 접기 또는 별도 문서 링크
그대로 둔다    Setup, Data Source Notice 등 사실 기술
```

**508줄을 다 고치려 하지 말 것.** 이 라운드는 진입 동선만 만든다.

## 2. 먼저 처리할 것 — 미커밋 변경

현재 `README.md`는 `M` 상태다(24 insertions / 12 deletions).
그 변경의 내용은 v3 요약 수치 갱신이며 **그 갱신값 자체가 이미 낡았다.**

```
원래 README     853 passed
미커밋 변경     875 passed     ← 이것도 낡음
2026-08-06 실측  1,269 passed
```

처리:

```bash
git checkout -- README.md
```

로 되돌린 뒤 새로 작성한다. **이 되돌리기를 먼저 하고, 그 사실을 보고에 적는다.**
되돌리기 전에 `git diff README.md > ` 로 내용을 보고서에 남겨둘 것
(버리는 판단의 근거를 남기기 위함).

## 4. 기존 본문 처리

`Setup` 이하 v1/v2 커맨드 섹션들은 **지우지 않는다.** 다음 중 하나로 격하한다.

- 하단으로 이동하고 상위 제목을 `## v1/v2 재현 (레거시)` 로 변경
- 또는 `<details>` 로 접기

**어느 쪽이든 커맨드 내용 자체는 수정하지 않는다.**
동작 확인 없이 커맨드를 고치면 잘못된 재현 절차를 배포하게 된다.

Product Free RAG 실행 방법은 `PORTFOLIO.md` §8에 있으므로 README에서는
링크만 건다. 중복 기술하지 않는다.

## 8. 성공 기준

저장소를 처음 여는 넥슨 담당자가 **스크롤 없이** 다음 셋을 알 수 있으면 성공이다.

1. 이게 무슨 프로젝트인가
2. 어디를 눌러야 제대로 된 설명이 나오나
3. 지금 어디까지 됐고, 그 숫자를 얼마나 믿어도 되나

README를 길게 만드는 게 아니라 **`PORTFOLIO.md`로 보내는 게** 목표다.
