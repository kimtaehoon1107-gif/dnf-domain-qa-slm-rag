## 2. 규명해야 할 질문

`table_value_spans()` (src/v3/grounded_answer_generator.py:248)는
`subject + relation`으로 표/행/속성을 고릅니다. **어느 단계에서 떨어지는지**를
17문항 전부에 대해 확정해 주세요.

각 요구마다 아래 4단계 중 **어디서 0이 되는지** 기록:

| 단계 | 판정 대상 | 실패 시 의미 |
|---|---|---|
| **S1 표 선택** | `_surface_match_score(subject, view["table_subject"])` | 요구가 어느 표인지 못 정함 |
| **S2 행 선택** | `_surface_match_score(subject, row["subject"])` | 표는 맞는데 행을 못 찾음 |
| **S3 수량 한정자** | `_numeric_qualifiers` 필터 | 행 후보가 한정자에서 전멸 |
| **S4 속성 선택** | `_surface_match_score(relation, attribute)` | 행은 맞는데 어느 열인지 못 정함 |

### 산출 형식

### 주체 유사도로 span 랭킹하는 것 — 2회 측정, 2회 되돌림

frozen 95문항 전체 측정 결과입니다. gold 값 정확도 기준:

| 구성 | gold 정확 | 판정 |
|---|---:|---|
| A+B (값-우선만) | **22/44 = 50.0%** | 현재 기준선 |
| + 주체 정렬 (regex `_surface_match_score`) | 19/43 = 44.2% | NO-GO, 되돌림 (`409ed05d`) |
| + 주체 정렬 (Kiwi 조사 제거) | 18/42 = 42.9% | NO-GO, 되돌림 (`842f05bc`) |

**매처를 좋게 만들어도 더 나빠졌습니다.** 원인은 매처 품질이 아니라 구조입니다:

```
주체: 스페셜 클론 레어 아바타 풀세트 상자
정답 근거: "| 상점판매가격 | 4,000만 골드 |"
           ↑ 주체 이름이 한 글자도 없음. 상품명은 다른 셀에 있음
```

**정답 span이 주체를 언급하지 않는 경우가 많아서, 주체 존재로 순위를 매기면 정답을
체계적으로 끌어내립니다.** 그래서 `subject_surface_similarity.py`도 함께 삭제했습니다
(커밋 이력에는 남아 있습니다).

### 방법론 경고 — 같은 함정을 피하세요

조사 제거를 도입한 근거는 4건짜리 프로브에서 0/4 → 2/4 개선이었습니다.
**그 4건은 실패한 케이스에서 골랐습니다.** 실패 케이스가 나아지는 건 당연하고,
순효과와는 무관했습니다. 전체 95문항에서는 오히려 나빠졌습니다.

**실패 사례로 만든 프로브로 방향을 정하지 마세요.** 반드시 전체 95문항으로 재세요.

참고로 사용자 사전도 측정했고 **어느 형태로도 해롭습니다** (전체 이름 0/4, 단어 단위 1/4).
개체명이 한 토큰이 되면서 부분 매칭이 죽습니다.

**다만 위 결과는 전부 산문 span 랭킹 이야기입니다. 표 개체 셀은 조건이 다릅니다** —
조사가 안 붙고, 셀 경계가 명확합니다. 표 바인딩 실패 원인은 **열어봐야 압니다.**
위 S1~S4 계측이 그걸 판별합니다.

## 4. 유력 가설 (검증 대상이지 결론 아님)

**H1. planner의 `subject`가 표 행의 개체와 층위가 다르다.**
`2025년 4월 26일 시행 정책 · 허위 정보 유포 제재`에서 행 개체는 `허위 정보 유포`인데
subject는 정책 이름입니다. 실제 개체가 relation 쪽에 있습니다. → S2 전멸 예상

**H2. subject가 표 제목을 포함해 과도하게 길다.**
`마일리지샵 시즌6 증폭 보호권`에서 행 개체는 `증폭 보호권`뿐입니다. → S2 점수 저하

**H3. 조사·형태소.** 표 셀에도 조사가 붙은 경우. → 3장 참조

**H4. 속성명 불일치.** `가격` vs 열 제목 `판매 가격`/`마일리지`. → S4 탈락
