## 0. 배경 — R5가 드러낸 것

R5 귀속은 **원본 A6 one-shot(7월 말 파이프라인)** 기준입니다. 그 이후
런타임에 6가지가 적용됐고, **그 효과를 한 번도 재보지 않았습니다.**

```
번 → 회 정규화        →  A6-10 ×2, A6-28 복구 (S4 3건)로 추정
헤더 메타데이터 필터   →  A6-2 복구 확인 (S3 1건, 14시 → 15시)
R1 괄호 값 결합       →  A6-7 base_cooldown 복구 (S2 1건)
R2 표 도입문
내부 ? 분리           →  A6-14 근거 회수 (S3 1건)
cross-parent 완화
```

**실제 실패 14건 중 최소 6건이 이미 고쳐졌을 가능성이 있습니다.**

그리고 미적용 2건이 S2의 나머지 2건을 겨냥합니다.

```
랭킹 결합  1f8c20b   →  A6-1  transfer_limits   (표 형제 행 누락)
예약 fallback a3ebd70 →  A6-26 contract_price   (9,800 세라 누락)
```

## 3. A3 — shadow 상호작용 확인 🔴 (Qwen 0회)

각 변경은 **같은 기준선(A_current 40/4/5)에 대해 따로** 측정됐습니다.
**둘을 합친 결과는 측정된 적이 없습니다.**

```
기준선          40 full / 4 partial / 5 none
랭킹 결합 단독   41 / 3 / 5
예약 단독        41 / 3 / 5
둘 다           ?              ← 이번에 측정
```

### 판정 (사전 등록)

| 결과 | 해석 | 다음 |
|---|---|---|
| **42 이상** | 상호보완. 서로 다른 요구를 고침 | ✅ A4 진행 |
| **41** | 한쪽이 다른 쪽을 상쇄 | ⚠️ 어느 쪽이 묻히는지 보고 후 A4 진행 |
| **40 이하 또는 감소 발생** | ❌ 상호작용이 해로움 | **A4 중단.** 감소 건 전문 보고 후 하나만 남길지 결정 |

**값 유형별로 분리해 보고하십시오.**
```
numeric · date · time · currency  →  판정 근거
descriptive                        →  별도 (A6-17·29 위양성 사례)
```
