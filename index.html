01 · Problem

관련 문서를 찾는 것만으로는
정답이 되지 않았습니다.

게임 문서는 같은 숫자도 조건과 개정 시점에 따라 의미가 달라집니다. 검색·생성·검증·인용을 분리해 어느 단계에서 답이 사라졌는지 추적했습니다.

CONDITION BINDING

같은 스킬 이름, 다른 조건

평시 값과 특정 개화 조건의 값이 한 문서에 함께 있으면, 숫자는 모두 근거에 존재해도 조건을 놓친 오답이 만들어집니다.

TABLE STRUCTURE

표의 구조가 곧 의미

rowspan·colspan을 잃으면 아이템·난이도·수량의 연결이 끊어집니다. 완전한 표와 검색용 atomic row를 함께 보존했습니다.

TIME & REVISION

게시일과 적용일은 다릅니다

현재·최신·진행 중 같은 집합 질문은 메타데이터로 계산하고, 특정 문서의 사실은 일반 검색으로 분리했습니다.

HONEST EVALUATION

채점기도 틀릴 수 있습니다

동일한 봉인 출력이 자동 채점 7/32, 사람 원문 감수 20/32였습니다. 자동 점수와 의미 품질을 같은 숫자로 부르지 않았습니다.

02 · Architecture

모델은 해석하고,
서버는 근거를 지킵니다.

질문 의미를 규칙으로 모두 선점하지 않습니다. 검색된 근거를 짧게 제공하고, 생성은 한 번만 호출하며, 값과 인용은 결정적으로 검증합니다.

질문 정규화

Unicode와 띄어쓰기 변형을 정규화합니다.

메타데이터 분기

집합 연산 질문만 별도 계산 경로로 보냅니다.

Hybrid 검색

BM25 20 + BGE-M3 20을 0.25 / 0.75로 결합합니다.

BGE reranker

요구별 후보를 재정렬하고 parent당 최대 2개를 남깁니다.

Atomic evidence

관련 문장·표 행을 E1~E8로 압축합니다.

조건부 응답

구조가 충분한 표는 서버, 나머지만 Qwen3 8B가 답합니다.

Bounded verifier

E번호·숫자·날짜·화폐·질문 관계를 검사합니다.

인용·표 복원

서버가 보존한 원문 좌표와 완전한 표를 렌더링합니다.

핵심 경계: 순수한 2축 O/X 비교표와 구조가 충분한 종류·보상 표는 Qwen을 호출하지 않습니다. 수량·혼합·모호 문맥만 생성 모델로 폴백합니다.

05 · Evaluation

봉인 결과와 개발 진단을
섞지 않았습니다.

문항·정답 계약을 SHA로 동결하고 한 번 실행했습니다. 결과를 본 뒤 고친 실험은 adaptive로 분리해 공식 헤드라인을 바꾸지 않았습니다.

TYPED · SEALED 37/64

06 · Failure analysis

오답보다 먼저
오답이 생긴 단계를 찾았습니다.

검색·근거 구성·생성·검증을 분리해 수정 범위를 좁혔습니다. 좋아진 결과뿐 아니라 과차단과 롤백도 같은 형식으로 기록했습니다.

병합셀 표 손실

Root cause

파서가 rowspan·colspan 관계를 잃어 품목·난이도·수량이 분리됨

Resolution

표 구조를 계산해 하나의 atomic row로 결속하고 비교 claim을 묶어 검증

정답 claim 과차단

Root cause

slot 25의 정확한 네 번째 claim을 relevance threshold가 adaptive 3/3에서 반복 제거

Lesson

차단 수가 아니라 실제 오답 차단과 실제 정답 차단을 함께 측정

잘못 설계한 갱신 게이트

Root cause

동적 값으로 좌표가 바뀌는데도 과거 좌표 33/33 유지를 승격 조건으로 사용

Resolution

좌표 유지율을 관측값으로 강등하고, 정답 본문·revision·인용 복원을 실제 게이트로 변경

07 · Limits

공개는 가능하지만,
제품 기본값은 아닙니다.

실험 경로를 완성품처럼 포장하지 않습니다. 현재 결과가 말할 수 있는 범위와 다음 승격 조건을 함께 공개합니다.

현재 NO-GO

sealed 사람 감수 20/32는 목표 80%에 미달합니다. unsupported overclaim, 조건·주어 결속, 모호한 clarification 선택지 문제도 남아 있습니다.

다음 승격 조건

새로운 사람 검수 봉인 세트에서 정확도·false-full·overclaim·인용·지연을 다시 측정하고, 코퍼스 revision 승격과 롤백을 자동화해야 합니다.
