# Subject-anchored full Arm + split schema 32문항 의미 재감사

## 정정 사유

기존 분석은 `all_evidence_spans_hit`를 strict 답변 정확도처럼
표현했다. 그러나 이 지표는 평가 세트가 지정한 `evidence_span`을 선택된
인용이 문자 그대로 포함하는지를 측정한다. 답변 값이 맞는지는 직접
채점하지 않는다.

이 때문에 다음 두 종류의 오류가 모두 확인됐다.

- 12번처럼 답은 맞지만 더 짧거나 다른 동등 근거를 인용해 실패하는
  false negative
- 7번처럼 답은 틀렸지만 인용문 안에 gold span이 들어 있어 성공하는
  false positive

따라서 기존 `14/32`는 답변 정답률로 사용할 수 없다.

## 수정 결과

| 평가축 | 결과 |
|---|---:|
| 후보 회수 | 31/32 |
| raw 모델 답변 의미 정답 | **28/32 (87.5%)** |
| verifier 이후 최종 답변 의미 정답 | **17/32 (53.1%)** |
| 최종 답변과 인용의 의미적 지지 모두 충족 | **16/32 (50.0%)** |
| gold-span 문자 일치 | 14/32 (43.8%) |
| 실제 answer-level false-full | **1/32** |

raw 모델 답변은 각 고정 requirement 호출이 요구한 값을 맞혔는지
판정했다. 최종 답변은 verifier가 차단한 뒤 사용자에게 실제 노출되는
requirements 전체가 맞고 빠짐없는지를 판정했다. 짧은 정답, 동등한 공식
표현, 질문에 충분한 부분 인용은 정답으로 인정했다.

## 실제 실패의 분해

raw 모델이 답 내용을 틀리거나 누락한 문항은 네 개다.

- 5번: 적용 시점 오답
- 7번: 적용 시점 오답
- 18번: 환불 대상 누락
- 20번: 환불 대상과 입금 계좌 요구 매핑 실패

raw 모델은 맞았지만 verifier 때문에 최종 정답이 되지 못한 문항은
11개다.

- 2, 4, 9, 13, 14, 16, 17, 21, 22, 24, 32번

12번은 답변 내용 정답이다. gold-span 불일치는 답변 오류로 세지 않는다.
다만 선택한 첫 구매 혜택 인용이 그 관계를 직접 증명하지 않아
`답변+인용 의미 지지` 지표에서만 실패로 판정한다.

## 올바른 해석

- 모델 자체의 의미 선택 능력: 이 adaptive 32문항에서 28/32
- 현재 verifier를 포함한 제품 출력 완성도: 17/32
- 의미적으로 근거까지 완결된 제품 출력: 16/32
- gold-span 문자 일치 14/32는 회귀 검사 보조 지표로만 사용
- 이 세트는 adaptive development set이므로 독립 blind 성능으로 부르지 않음

기존 `false_full_case_ids`도 실제 answer-level false-full 목록이 아니다.
실제 답이 틀렸는데 `full_answer`로 노출된 것은 7번 한 건이다.
