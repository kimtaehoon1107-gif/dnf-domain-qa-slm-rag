# Simple Domain RAG — Qwen3 4B Instruct vs Qwen3 8B semantic comparison

## 평가 조건

- 평가 세트: 현재 32문항
- 검색: BGE-M3 기반 기존 Simple Domain RAG 검색
- 4B 모델: `qwen3-4b-instruct-2507:ctx8192`
- 8B 모델: `qwen3-8b:ctx8192`
- 판정 기준: gold의 특정 문자열과 동일한지만 보지 않고, 최종 사용자 노출 답변의 의미가 질문을 충족하며 인용 근거가 직접 지지하는지 사람이 재검수
- 주의: 4B의 16·25·27번은 검색 실패가 아니라 출력 스키마 검증 오류다. 예외 처리 과정에서 결과 파일의 후보 목록도 비워졌으므로 자동 집계의 후보 회수 `25/32`를 검색 성능으로 해석하면 안 된다.

| 지표 | 4B Instruct | 8B |
|---|---:|---:|
| 최종 의미 정답 + 직접 근거 | **20/32 (62.5%)** | **19/32 (59.4%)** |
| 실제 잘못된 full answer | **3/32** | **2/32** |
| 잘못된 partial answer | **2/32** | **1/32** |
| 안전한 incomplete/abstain 또는 스키마 차단 | **7/32** | **10/32** |
| 생성 스키마 오류 | **3/32** | **0/32** |
| 평균 LLM 지연 | **11.62초/문항** | **30.53초/문항** |
| 기존 gold-literal 보조 지표 | 13/32 | 15/32 |

4B는 최종 정답이 8B보다 1문항 많고 약 2.6배 빠르다. 반면 잘못된 답을 노출한 문항은 4B가 5건, 8B가 3건이며, 4B에는 출력 스키마 오류가 3건 있다. 따라서 현재 결과만으로는 4B가 명백한 품질 승자라고 보기 어렵다. 속도·답변률은 4B가 좋고, 안전성과 스키마 준수는 8B가 조금 더 안정적이다.

## 해석

1. 4B가 “평균 이하라서 못 쓰는 모델”인 결과는 아니다. 같은 파이프라인에서 8B보다 의미 정답이 1건 많고 훨씬 빠르다.
2. 다만 4B의 우위는 작고, 세 번의 스키마 오류 때문에 운영 안정성은 아직 부족하다.
3. 21~24번의 길드 운영정책 문제는 모델 크기보다 검색·라우팅 문제의 영향이 크다. 두 모델 모두 일반 계정/운영정책 근거에 끌렸다.
4. 4B의 7·23·24번은 근거 선택 의미 오류를 full answer로 노출했으므로 fail-closed 의미 검증이 필요하다.
5. 기존 gold-literal은 공식적으로 동등한 다른 문장을 오답 처리할 수 있으므로 보조 진단값으로만 유지해야 한다.

## 결론

- 속도를 중시한 실험·로컬 데모: 4B Instruct를 계속 시험할 가치가 있다.
- 현재 그대로의 안전한 운영 후보: 8B가 스키마 준수와 오답 노출에서 조금 더 안정적이다.
- 다음 최소 실험: 4B에 스키마 자동 복구 또는 1회 재시도만 추가하고 같은 32문항을 다시 실행한다. 16·25·27번이 복구되면서 새 false-full이 생기지 않는지만 보면 된다.
