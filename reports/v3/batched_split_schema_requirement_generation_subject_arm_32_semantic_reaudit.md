## 8번 ID 보정 재확인

최초 32문항 실행에서는 모델이 고정 ID 대신 `1, 2, 3`을 출력했다.
정확한 개수의 `1..N`만 고정 ID로 복원하는 fail-closed 보정을 추가했고
관련 단위 테스트를 통과했다.

실모델 단독 재실행에서는 모델이 처음부터
`requirement_1..3`을 정상 반환했으며 생성 오류는 0이었다. 세 값은 모두
20%로 맞았지만 모델이 복사한 quote의 문자 차이 때문에 기존 verifier가
세 요구를 모두 차단했다. 따라서 남은 병목은 ID가 아니라 문자열 verifier다.

## 결론

질문별 배치는 이전 요구별 호출보다 정확도와 속도가 모두 개선됐다.
다음 실험에서는 검색·모델·배치 호출을 고정하고 verifier만
`evidence_ref + typed value + relation-aware` 방식으로 교체한다.
